# 应用岛实施计划

目标：以 iPad App 启动器集中展示工作区全部项目，使用真实 Logo、名称及已验证的 Pages 正式网址，新窗口打开。
架构：原生 HTML/CSS/ES modules，public/projects.json 是项目目录的唯一来源，Node 仅用于校验与静态构建，无生产后端。main 直接开发。

1. 先测试目录校验、发布状态、危险 URL、搜索及收藏过滤，再实现目录逻辑。
2. 创建紫蓝玻璃质感 App 外壳、侧栏/底部导航、真实应用卡片与搜索空状态；CSS 实现轻量动效与减少动态效果降级。
3. 增加项目登记脚本，未发布条目可见但不可点击；正式 URL 经 HTTPS 访问核验后激活。Logo 从项目资源复制，保留来源说明。
4. 更新父级、既有项目及新项目规范，落实新建登记、发布后更新和名称图标变更同步。
5. 完成单元测试、浏览器多视口/新窗口/存储受限/加载失败测试、静态设计审查与构建，再提交发布并验证正式地址。

审查重点：未发布网址误激活、不安全链接、图标加载失败、浏览器拒绝本地存储、iPad 横竖屏与手机布局。发布方案按账号权限及用户对公开产物仓库的确认执行。
